SiafuDB is an embedded, graph-native database. It has the same shape as SQLite: open a database, execute queries, get results. Everything is a graph underneath, so relationships are first-class and context is traversable.

<Note>
  SiafuDB is pre-release software, and the API will change before 1.0. Two
  packages are published: `@bundu/siafudb-web` 0.4.0 on npm for the browser,
  and `siafudb-core` 0.4.0 on crates.io for Rust. See [Status](#status) for
  what works today and what is design direction.
</Note>

The goal is a database for the device, the edge, and Web3 pods, with data that syncs through the Graph Sync Protocol and privacy transformations on the way out. Today, sync covers one case: the devices of one person. Transformations are not built.

## The nervous system

This is the long-term vision. SiafuDB, the Graph Sync Protocol, and [NTL](https://ntl.nyuchi.com) are meant to form one computing model:

- **AI is the brain.** Reasons, decides, learns.
- **SiafuDB is the memory.** Holds context on every device, at every edge, in every pod.
- **NTL is the nervous system.** Carries signals between nodes through a neural transport layer that learns as it routes.

In that model, the Graph Sync Protocol keeps memory coherent across the body, and its training loop lives inside NTL. NTL is a separate project. SiafuDB does not connect to it today.

## Status

**Released, pre-release quality:**

- An embedded graph database for the browser and for Rust. You query it with Cypher and bound parameters. See the [Quickstart](/guides/quickstart).
- Encrypted storage in the browser.
- [Sync v0](/sync/v0) in the browser package. The devices of one person stay in step through a relay that stores only ciphertext.
- Change capture in `siafudb-core`. See the [Sync API](/api-reference/sync).

**Design direction, not built:**

- The GSPA and GSPN transports, and anything that involves NTL.
- Transformations, sharing between people, Personal and Network fragments, and per-vertex authority.
- Packages for Python, Node.js, Go, Swift and Kotlin.

The software has had no external audit. See the [roadmap](/governance/roadmap) for the plan.
