This page describes the planned path from GSPA to GSPN. In the design, the move is a transport swap. The mutation model, the schema, and the authority rules do not change. Only the way a signal gets from one fragment to the next changes.

## Planned prerequisites

- **NTL reachable on the network.** See [NTL — First Steps](https://ntl.nyuchi.com/research/06-first-steps).
- **IPv6** or dual-stack addressing. GSPN assumes neural addresses, which are IPv6-native.
- **Synapse topology** defined on the NTL side — where signals originate, where they terminate, what transforms attach to each synapse.

## Swapping the transport (design)

No API for this exists yet, so this page shows no code. The plan is that you point a fragment at an NTL synapse instead of a GSPA endpoint.

In the design, the emitter no longer worries about destinations. It hands the mutation to NTL as a signal. NTL decides which synapses fire and which transformations apply.

## Where transforms would live

In the GSPA design, the emitter applies transforms before the wire. In the GSPN design, transforms are attached to synapses. The names below are illustrative:

| Synapse                      | Transform                |
| ---------------------------- | ------------------------ |
| `synapse://platform-ingress` | `StripPII`               |
| `synapse://analytics`        | `Anonymise`, `Aggregate` |
| `synapse://owner-feedback`   | `Anonymise`              |

Moving transforms to the network would mean a single emitted signal can feed multiple destinations with different projections — no duplicate serialisation.

## Learned routing (design)

In the design, synapses retain weights. Frequently-travelled paths strengthen; cold paths decay. Over time, a deployment of SiafuDB fragments connected through NTL learns its own topology. See [NTL — Twelve Principles](https://ntl.nyuchi.com/research/05-twelve-principles).

## Fall-back (design)

The plan is that GSPN degrades to GSPA when NTL is unreachable. The graph stays coherent, and you lose adaptive routing until the neural layer comes back.
