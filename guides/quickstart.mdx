SiafuDB is published for the browser (npm) and for Rust (crates.io). It is
pre-release software: the API will change before 1.0.

## In the browser

The browser package runs the graph engine as WebAssembly in a Worker and
keeps the data encrypted in the browser's storage. It needs a secure context
(`https://` or `localhost`) and Node 24 for tooling.

```sh
npm install @bundu/siafudb-web
```

```ts
import { SiafuDB } from "@bundu/siafudb-web";

const db = await SiafuDB.open("notes");

await db.execute("CREATE (:Note {title: $t})", { t: "first note" });

const { columns, rows } = await db.query("MATCH (n:Note) RETURN n.title");
console.log(columns, rows); // ["n.title"] [["first note"]]
```

Always pass values as parameters (`$t`), never by building query text.

With Vite, add this so the Worker and the WebAssembly file are bundled:

```ts
// vite.config.ts
import { defineConfig } from "vite";

export default defineConfig({
  build: { target: "esnext" },
  worker: { format: "es" },
  optimizeDeps: { exclude: ["@bundu/siafudb-web"] },
});
```

In an Astro project, put the same settings under `vite:` in
`astro.config.mjs` and run the component client-only
(`client:only`), never during server rendering.

The data survives a page reload. One tab can have a given database open at a
time; a second tab waits, or fails fast if you ask it to.

<Note>
  Tested in Chromium. Safari and Firefox have not been tested yet.
</Note>

## In Rust

Requires rustc 1.99 or newer.

```sh
cargo add siafudb-core serde_json
```

```rust
use serde_json::json;
use siafudb_core::SiafuDB;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let db = SiafuDB::open("./notes.siafu")?;

    let mut params = serde_json::Map::new();
    params.insert("t".into(), json!("first note"));
    db.execute_with_params("CREATE (:Note {title: $t})", params)?;

    let result = db.query("MATCH (n:Note) RETURN n.title")?;
    println!("{:?} {:?}", result.columns, result.rows);
    Ok(())
}
```

`SiafuDB::in_memory()` opens a database that keeps nothing on disk.
